# 第 5 部 3D へ

ここまでのスケッチは平面の上で完結していました。この部では**奥行き**を足します。

metaphor の 3D は、2D の続きとして始められます。ワールド座標は**ピクセル座標そのもの**で、原点は左上、y は下向き、`box(100)` は 100 ピクセルの立方体です。第 1 部 1.4 で覚えた座標感覚をそのまま持ち込めて、増えるのは z 軸 1 本だけです。

覚えることは 4 つあります。**形**（`box` や `sphere` などのプリミティブ）、**変換**（軸まわりの回転）、**カメラ**（どこから見るか）、**光**（何が当たっているか）。2D と違って、3D は**光を置かないと何も見えません**。

## この部の前提

第 1 部 1.4 の座標系と、第 2 部 2.5 の `push()` / `pop()` による「囲って戻す」規律をそのまま使います。5.8 のテクスチャは 2.8 の画像と 2.9 の `createImage()` を、動きのある節は第 3 部 3.1 の `frameCount` を前提にします。

## 5.1 3D 空間に入る

![左は 3D の plane と 2D の rect がぴたりと重なった赤い正方形。右は z を -300 / 0 / +80 に置いた 3 つの箱で、奥ほど小さく見える](https://i.gyazo.com/75fb68d168d6db9bf9bc0b1bb86e1964.png)

3D を描くのに、モードの切り替えや初期化は要りません。`draw()` の中で `box()` や `sphere()` を呼べば、それが 3D の描画になります。ただし 1 つだけ約束があります。

```swift
lights()      // これを忘れると、形はあっても真っ黒に見える
box(100)
```

2D の `circle()` は `fill()` の色でそのまま塗られますが、3D の形は**光の当たり方**で明るさが決まります。`lights()` は既定の平行光と環境光をまとめて入れる関数で、まずはこれを呼んでおけば形が見えます（光の種類は 5.5 で分けます）。

### 座標は 2D と同じ

実行結果の左側は、3D の `plane(140, 140)` の上に、同じ位置・同じ寸法の 2D の `rect()` を輪郭だけ重ねたものです。**ぴたりと一致します**。

```swift
push()
translate(150, 130, 0)
plane(140, 140)     // 3D
pop()

rect(80, 60, 140, 140)   // 2D。中心は同じ (150, 130)
```

これは偶然ではなく、既定のカメラが「z = 0 の平面がキャンバスと 1 対 1 で写る」位置に置かれているためです。2D で使っていた座標の勘がそのまま通じます。

もう 1 つ、実行結果から読めることがあります。**2D の描画は 3D の上に重なります**。白い枠が平面の手前に見えているのはそのためで、順番を入れ替えても変わりません。文字や UI を 3D シーンの上に重ねたいときは、この性質がそのまま使えます。

### z を動かす

右側の 3 つの箱は、大きさも y も同じで、z だけが違います。奥（負の値）ほど小さく、手前（正の値）ほど大きく写ります。

既定のカメラは z ≈ 312 の位置にいます（`(height / 2) / tan(π/6)` の計算結果です）。ここに近づくほど拡大され、通り越すと視界から消えます。手前に置くときは 100 ピクセル程度から試すのが安全です。

<!-- tutorial-snippet: 05-ThreeD/01-Space -->
```swift
import metaphor

@main
final class Space: Sketch {
    var config: SketchConfig {
        SketchConfig(width: 640, height: 360, title: "Space")
    }

    func setup() {
        noLoop()
    }

    func draw() {
        background(18)

        // 3D にもライトが要る。lights() は既定の平行光と環境光を入れる
        lights()
        noStroke()

        // z = 0 に置いた 140x140 の平面。中心は (150, 130)
        fill(230, 90, 70)
        push()
        translate(150, 130, 0)
        plane(140, 140)
        pop()

        // 同じ寸法・同じ位置の 2D の矩形を輪郭だけ重ねる。ずれない
        noFill()
        stroke(255)
        strokeWeight(2)
        rect(80, 60, 140, 140)

        // z だけを変えた 3 つの箱。奥（負）ほど小さく、手前（正）ほど大きい。
        // カメラは z ≈ 312 にいるので、それ以上手前へ出すと視界から消える
        noStroke()
        fill(240, 190, 80)
        for (i, z) in [Float(-300), 0, 80].enumerated() {
            push()
            translate(340 + Float(i) * 90, 200, z)
            box(70)
            pop()
        }

        fill(200)
        textSize(13)
        textAlign(.center)
        text("3D の plane(140, 140) と 2D の rect が重なる", 170, 34)
        text("z = -300", 340, 330)
        text("z = 0", 430, 330)
        text("z = +80", 520, 330)
    }
}
```

実行: `cd Examples/Tutorial/05-ThreeD/01-Space && swift run`

## 5.2 プリミティブ

![box・sphere・plane・cylinder・cone・torus と、分割数を 4 / 8 / 24 と変えた球が並ぶカタログ](https://i.gyazo.com/426f150d266d5b6bb14db5d32eabe9c5.png)

組み込みの立体は 6 種類です。すべて**現在の座標系の原点を中心**に置かれるので、位置は `translate()` で決めます。

| 関数 | 形 | 大きさの決め方 |
|---|---|---|
| `box(size)` / `box(w, h, d)` | 直方体 | 辺の長さ |
| `sphere(radius, detail:)` | 球 | 半径 |
| `plane(w, h)` | 平面（xy 平面、法線は +z） | 幅と高さ |
| `cylinder(radius:height:detail:)` | 円柱 | 半径と高さ |
| `cone(radius:height:detail:)` | 円錐 | 底面の半径と高さ |
| `torus(ringRadius:tubeRadius:detail:)` | ドーナツ | 輪の半径とチューブの半径 |

数値はすべてピクセル相当です。`sphere(45)` は直径 90 ピクセルの球になります。

### detail は「何角形で近似するか」

球・円柱・円錐・トーラスは、実際には多数の三角形で作られた近似です。`detail` はその分割数で、既定は 24 です。

実行結果の下の段は同じ `sphere(45)` を `detail: 4` / `8` / `24` で並べたものです。4 では明らかな多面体、8 でもまだ角が見え、24 で滑らかに見えます。

分割数を上げるほど頂点が増えます。1 つ 2 つなら気になりませんが、数千個を描くなら下げる価値があります（5.10）。逆に、大きく映る球だけ `detail: 48` にする、といった使い分けもできます。

<!-- tutorial-snippet: 05-ThreeD/02-Primitives -->
```swift
import metaphor

@main
final class Primitives: Sketch {
    var config: SketchConfig {
        SketchConfig(width: 640, height: 360, title: "Primitives")
    }

    func setup() {
        noLoop()
    }

    func draw() {
        background(18)
        lights()
        noStroke()

        // 上の段: 5 種類のプリミティブ。少し傾けると立体だと分かる
        fill(235, 180, 90)
        shape(centeredAt: 72, y: 105, label: "box(80)") { box(80) }
        shape(centeredAt: 196, y: 105, label: "sphere(45)") { sphere(45) }
        shape(centeredAt: 318, y: 105, label: "plane(90, 90)") { plane(90, 90) }
        shape(centeredAt: 437, y: 105, label: "cylinder(38, 84)") {
            cylinder(radius: 38, height: 84)
        }
        shape(centeredAt: 556, y: 105, label: "cone(40, 88)") {
            cone(radius: 40, height: 88)
        }

        // 下の段: トーラスと、同じ球を detail だけ変えたもの
        fill(110, 190, 200)
        shape(centeredAt: 80, y: 250, label: "torus(40, 16)") {
            torus(ringRadius: 40, tubeRadius: 16)
        }
        shape(centeredAt: 230, y: 250, label: "sphere detail: 4") { sphere(45, detail: 4) }
        shape(centeredAt: 380, y: 250, label: "detail: 8") { sphere(45, detail: 8) }
        shape(centeredAt: 535, y: 250, label: "detail: 24（既定）") { sphere(45, detail: 24) }
    }

    /// 1 つの形を、決まった傾きと中央揃えのラベル付きで置く。
    private func shape(centeredAt x: Float, y: Float, label: String, body: () -> Void) {
        push()
        translate(x, y, 0)
        rotateX(-0.5)
        rotateY(0.7)
        body()
        pop()

        pushStyle()
        fill(190)
        textSize(12)
        textAlign(.center)
        text(label, x, y + 78)
        popStyle()
    }
}
```

実行: `cd Examples/Tutorial/05-ThreeD/02-Primitives && swift run`

## 5.3 3D の変換

![上段は rotateX / rotateY / rotateZ で回した 3 枚の板と、赤い目印の球。下段は入れ子の座標系で、親の球のまわりを子の球が回っている](https://i.gyazo.com/d097b3c93f47e2f19618325d1ca1d835.png)

![3 枚の板がそれぞれの軸で回り続け、下では子の球が親の球のまわりを回る](https://i.gyazo.com/76c06176e32fd10487219dd84900d41f.webp)

2D では回転は 1 種類でした（`rotate()`）。3D では**どの軸のまわりに回すか**を選びます。

| 関数 | 回る軸 | 見え方 |
|---|---|---|
| `rotateX(a)` | 横軸 | 前後に倒れる（お辞儀） |
| `rotateY(a)` | 縦軸 | 左右に振り向く |
| `rotateZ(a)` | 奥行き軸 | 画面内で回る（2D の `rotate()` と同じ） |

実行結果の上の段は、同じ板と目印を 3 通りに回したものです。角度はラジアンで、正の向きは「その軸の正方向から原点を見て時計回り」になります。

`translate()` も 3 引数の形があり、`push()` / `pop()` は 2D と 3D の両方に効きます。つまり第 2 部 2.5 で覚えた「囲って戻す」規律はそのまま使えます。

```swift
push()
translate(320, 180, 0)
rotateY(a)
box(100)
pop()          // ここで座標系が元に戻る
```

### 入れ子は「座標系の中の座標系」

実行結果の下の段は、`rotateY()` を 2 段重ねたものです。中心の球のまわりを 1 つ目の球が回り、その球のまわりをさらに小さい球が回ります。

```swift
sphere(34)              // 中心

rotateY(a)              // ここから先は回った座標系
translate(130, 0, 0)
sphere(22)              // 中心を回る球

rotateY(a * 3)          // その中でさらに回る
translate(48, 0, 0)
sphere(11)              // 球を回る球
```

**変換は積み重なります**。子の位置は親の座標系の中で決まるので、親が回れば子もついて回ります。腕・車輪・惑星系のような「関節のあるもの」は、この入れ子だけで組み立てられます。

視点そのものを動かしたいときは変換ではなくカメラの仕事です。次の 5.4 で扱います。

<!-- tutorial-snippet: 05-ThreeD/03-Transform -->
```swift
import metaphor

@main
final class Transform3D: Sketch {
    var config: SketchConfig {
        SketchConfig(width: 640, height: 360, title: "Transform 3D")
    }

    func draw() {
        background(18)
        lights()
        noStroke()

        // 撮り直しても同じ絵になるよう、時刻ではなくフレーム数で回す。
        // 最初のフレームから傾いているように 0.7 ラジアンだけ足しておく
        let a = 0.7 + Float(frameCount) * 0.02

        // 上の段: 同じ形を x / y / z 軸まわりに回す。板と目印の球で向きが分かる
        marker(at: 110, y: 100, label: "rotateX(a)") { rotateX(a) }
        marker(at: 320, y: 100, label: "rotateY(a)") { rotateY(a) }
        marker(at: 530, y: 100, label: "rotateZ(a)") { rotateZ(a) }

        // 下の段: 入れ子。親の座標系の中で子が回る
        push()
        translate(320, 265, 0)

        fill(240, 190, 80)
        sphere(34)                    // 中心

        rotateY(a)                    // ここから先は「回った座標系」
        translate(130, 0, 0)
        fill(110, 190, 200)
        sphere(22)                    // 中心のまわりを回る球

        rotateY(a * 3)                // さらにその中で回る
        translate(48, 0, 0)
        fill(230, 90, 70)
        sphere(11)                    // 球のまわりを回る球
        pop()

        fill(190)
        textSize(12)
        text("入れ子の座標系: 親が回ると子もついて回る", 200, 348)
    }

    /// 板と目印を 1 組描く。rotate の掛け方だけを呼び出し側から差し込む。
    private func marker(at x: Float, y: Float, label: String, rotation: () -> Void) {
        push()
        translate(x, y, 0)
        rotation()

        fill(235, 180, 90)
        box(110, 110, 8)              // 薄い板。向きが変わると見え方が変わる

        translate(0, -55, 0)          // 板の「上端」に目印を置く
        fill(230, 90, 70)
        sphere(13)
        pop()

        pushStyle()
        fill(190)
        textSize(12)
        text(label, x - 34, y + 92)
        popStyle()
    }
}
```

## 5.4 カメラ

![灰色の床に立つ水色のビル群と中央の黄色い柱を、透視投影のカメラから見た絵](https://i.gyazo.com/bb81b5ee08cedaf5309c53b787fc5d64.png)

![同じビル群を、透視投影と平行投影で交互に見せる。平行投影では奥のビルも小さくならない](https://i.gyazo.com/4803701ef1a2faad4224d68002c1b241.webp)

既定のカメラは、キャンバスの中央（`width / 2`, `height / 2`）を、z ≈ 312 の位置から見ています。5.1 で 2D と 3D の座標が一致していたのは、この置き方のおかげです。

自分で置き直すときは `camera()` を使います。

```swift
camera(
    eye: SIMD3(x, y, z),          // カメラの位置
    center: SIMD3(cx, cy, cz),    // 見つめる点
    up: SIMD3(0, 1, 0)            // 上の向き（既定）
)
```

実行結果では `center` をシーンの中央に固定したまま、`eye` だけを円周上で動かしています。注視点が動かないので、シーンが回っているようにも、自分が回り込んでいるようにも見えます。

### 投影 — 遠近を付けるか、付けないか

カメラにはもう 1 つ、**投影**の設定があります。

| 関数 | 投影 | 見え方 |
|---|---|---|
| `perspective(fov:near:far:)` | 透視投影（既定） | 遠いものほど小さい |
| `ortho(left:right:bottom:top:near:far:)` | 平行投影 | 距離によらず同じ大きさ |

動きの証跡は前半が透視投影、後半が平行投影です。平行投影では床の手前と奥の幅が変わらず、柱の高さも位置によらず一定になります。図面のような見え方で、アイソメトリックな絵作りに向きます。

`ortho()` は引数を省くと**キャンバスの寸法（左上が原点）をそのまま視体積にします**。既定のカメラならこれで合いますが、`camera()` で視点を移したあとは範囲も自分で指定しないとシーンが枠から外れます。上のスケッチが左右上下を明示しているのはそのためです。

`fov`（視野角、既定は π/3）を小さくすると望遠レンズのように圧縮され、大きくすると広角になって遠近が強調されます。

### マウスで視点を回す

`orbitControl()` を `draw()` の中で呼ぶと、ドラッグで回転、スクロールでズームできるカメラになります。試行錯誤の間だけ入れておくと形の確認が速くなります。

```swift
func draw() {
    background(18)
    orbitControl()      // ドラッグで回る
    lights()
    box(100)
}
```

**注意点が 1 つあります**。`orbitControl()` のカメラは既定のカメラとは別物で、**ワールドの原点 (0, 0, 0) を距離 500 から見ます**。ピクセル座標の感覚で `translate(width / 2, height / 2, 0)` の位置に置いた形は、視界の外に出てしまいます。`orbitControl()` を使うときは、シーンを原点のまわりに組みます。

<!-- tutorial-snippet: 05-ThreeD/04-Camera -->
```swift
import metaphor

@main
final class Camera: Sketch {
    var config: SketchConfig {
        SketchConfig(width: 640, height: 360, title: "Camera")
    }

    // シーンの中心。既定カメラが見ている場所と同じ位置に置く
    var center: Vec3 { Vec3(width / 2, height / 2, 0) }

    func draw() {
        background(18)
        ambientLight(60)
        directionalLight(0.3, 0.9, -0.4)
        noStroke()

        let t = Float(frameCount) * 0.02

        // 前半は透視投影、後半は平行投影。同じシーンの見え方の違いが分かる
        let isPerspective = (frameCount / 60) % 2 == 0
        if isPerspective {
            perspective(fov: PI / 3)
        } else {
            // ortho() の既定の範囲はキャンバスの寸法（原点が左上）なので、
            // camera() で視点を移したときは範囲も視点に合わせて指定する
            ortho(
                left: -width * 0.6, right: width * 0.6,
                bottom: height * 0.6, top: -height * 0.6
            )
        }

        // 視点をシーンのまわりで回す。center は動かさないので、常に真ん中を見続ける
        let radius: Float = 430
        camera(
            eye: SIMD3(
                center.x + cos(t) * radius,
                center.y - 150,
                center.z + sin(t) * radius
            ),
            center: SIMD3(center.x, center.y, center.z)
        )

        // 見られる側のシーン: 床と、中央の柱と、それを囲む 6 本の柱
        fill(95)
        push()
        translate(center.x, center.y + 70, center.z)
        rotateX(PI / 2)
        plane(520, 520)
        pop()

        fill(240, 190, 80)
        push()
        translate(center.x, center.y, center.z)
        box(60, 130, 60)
        pop()

        fill(110, 190, 200)
        for i in 0..<6 {
            let angle = Float(i) * TWO_PI / 6
            push()
            translate(center.x + cos(angle) * 150, center.y + 30, center.z + sin(angle) * 150)
            box(40, 70, 40)
            pop()
        }

        fill(200)
        textSize(14)
        text(isPerspective ? "perspective(fov: π/3)" : "ortho(左右上下を指定)", 22, 34)
    }
}
```

## 5.5 ライティング

![床の上に並んだ 5 つの球。左半分が暖色の pointLight、右半分が寒色の spotLight に照らされている](https://i.gyazo.com/9dde69f4dc5712e7753a216b7de9f903.png)

`lights()` の中身を分解します。光は 4 種類あり、いくつでも足せます。

| 関数 | 種類 | 持っているもの |
|---|---|---|
| `ambientLight(strength)` | 環境光 | 明るさだけ。すべての面を一律に持ち上げる |
| `directionalLight(x, y, z)` | 平行光 | 向きだけ。太陽のように、位置によらず同じ角度で当たる |
| `pointLight(x, y, z, color:falloff:)` | 点光源 | 位置。距離で減衰する |
| `spotLight(x, y, z, dx, dy, dz, angle:falloff:color:)` | スポット | 位置と向きと開き角 |

実行結果は同じ 5 つの球を並べたものです。全体には環境光と平行光が当たり、左の 2 つには暖色の点光源、右の 2 つには寒色のスポットが届いています。位置を持つ光は**近くだけを照らす**ので、こうして並べると差が見えます。

### 向きは「光が進む向き」

`directionalLight()` に渡すのは光源の位置ではなく、**光が進む向き**です。しかも y は画面と同じく下向きです。

```swift
directionalLight(0, 1, 0)    // 真上から下へ差す光
directionalLight(0, -1, 0)   // 真下から上へ差す光
```

z を負にすると手前から奥へ差すので、こちらを向いた面が明るくなります。**画面に向いた面が暗いときは、まず z の符号を疑います**。

### 減衰は思っているより速い

`pointLight` / `spotLight` の `falloff` は距離による減衰の係数で、距離の 2 乗まで効きます。metaphor のワールド座標はピクセル単位なので、**既定値（0.1）のままだと数百ピクセル先には届きません**。200 ピクセル先で明るさは 0.3% ほどになります。

画面全体を照らしたいときは `0.001` 以下を指定します。上のスケッチでは `0.0006` を使っています。

### 環境光は影の中の明るさ

`ambientLight()` は影の中でも減衰しません（5.7）。0 にすると光の当たらない面は完全な黒になり、輪郭以外が見えなくなります。既定では `colorMode` のレンジの 30%（0〜255 なら 76.5 相当）が入っています。

なお `ambientLight()` の値は `fill()` と同じレンジ（既定 0〜255）ですが、**`specular()` にグレー値を渡す形だけはレンジに従いません**（[#527](https://github.com/shinyaoguri/metaphor/issues/527)）。ハイライトの色は `specular(Color(r: 0.35, g: 0.35, b: 0.35))` のように `Color` で渡すのが安全です。

<!-- tutorial-snippet: 05-ThreeD/05-Lighting -->
```swift
import metaphor

@main
final class Lighting: Sketch {
    var config: SketchConfig {
        SketchConfig(width: 640, height: 360, title: "Lighting")
    }

    func setup() {
        noLoop()
    }

    func draw() {
        background(10)
        noStroke()

        // 影のない場所の明るさ。これを 0 にすると光の当たらない面は真っ黒になる
        ambientLight(55)

        // 「光が進む向き」を渡す。y は画面下向きなので (0.3, 1, -0.35) は
        // 左上の手前から、奥下へ向かって差す光になる
        directionalLight(0.3, 1, -0.35, color: Color(r: 0.55, g: 0.55, b: 0.55))

        // 位置を持つ光。近くほど明るく、離れるほど falloff で減衰する。
        // 減衰は距離の 2 乗まで効くので、ピクセル単位の座標では既定値（0.1）は
        // 強すぎる。数百ピクセル先まで届かせるには 0.001 以下にする
        pointLight(180, 170, 170, color: Color(r: 1, g: 0.5, b: 0.3), falloff: 0.0006)

        // 円錐状に照らす光。位置と向き、そして開き角を持つ
        spotLight(
            470, 40, 150, 0, 1, -0.12,
            angle: 0.5, falloff: 0.0006,
            color: Color(r: 0.5, g: 0.75, b: 1)
        )

        // ハイライトの色と鋭さ。shininess が大きいほど小さく鋭く光る。
        // グレー値を渡す specular(_:) は 0〜1 で解釈される（#527）ので Color で渡す
        specular(Color(r: 0.35, g: 0.35, b: 0.35))
        shininess(64)

        // 床。plane は xy 平面なので、x 軸まわりに 90 度倒して水平にする
        fill(90)
        push()
        translate(320, 300, -60)
        rotateX(PI / 2)
        plane(900, 620)
        pop()

        // 光の違いが出るように、同じ球を横一列に並べる
        fill(205)
        for i in 0..<5 {
            push()
            translate(100 + Float(i) * 110, 235, 20)
            sphere(45)
            pop()
        }

        fill(200)
        textSize(12)
        text("ambientLight + directionalLight は全体に効く", 22, 32)
        text("pointLight（暖色・左）", 90, 110)
        text("spotLight（寒色・右）", 420, 110)
    }
}
```

## 5.6 マテリアルと PBR

![roughness を 0.05 から 1.0 まで変えた 5 列、metallic 0 と 1 の 2 行に球を並べた一覧。金属の行はハイライトが小さく鋭い](https://i.gyazo.com/8050a09a82474e4db5309ec649ec84c4.png)

同じ光でも、当たる**面の性質**で見え方は変わります。metaphor には陰影の計算方式が 2 つあります。

| 方式 | 設定する値 | 切り替え |
|---|---|---|
| Blinn-Phong（既定） | `specular()`, `shininess()`, `emissive()` | 既定 |
| PBR（物理ベース） | `metallic()`, `roughness()`, `ambientOcclusion()` | `roughness()` を呼ぶと自動、または `pbr(true)` |

Blinn-Phong は「ハイライトの色と鋭さ」を直接指定する古典的な方式です。PBR は「金属かどうか」「表面が粗いかどうか」という材質の言葉で指定します。**`roughness()` を呼んだ時点で PBR に切り替わる**ので、混ぜて使わないようにします。

実行結果は PBR の格子です。上の段は非金属（`metallic(0)`）、下の段は金属（`metallic(1)`）で、左から右へ `roughness` を上げています。左端はハイライトが小さく鋭く、右端はぼやけて一様になります。

### 金属が暗いのは仕様の途中

下の段の金属が全体に暗いのは、**金属は周囲の景色を映すことで見える**のに、映すものが無いからです。直接光のハイライトだけが残ります。

映すものを与えるのが `environment()` です。

```swift
environment(.studio)   // setup() で 1 回呼べばよい
```

これだけで、周囲の環境（イメージベースドライティング = IBL）が金属に映り込み、背景も
その環境になります。プリセットは `.studio` / `.sunset` / `.overcast` の 3 種で、画像ファイル
などのアセットは要りません。`environment()` を呼ばなければ絵はこれまでどおりです。

映り込みが効くのは PBR（`roughness()` を呼んだ状態）だけで、Blinn-Phong の絵は変わりません。
背景を出さずライティングだけ欲しいときは `environment(.studio, background: false)` とします。

PBR テクスチャ（normal / roughness マップ）は [#293](https://github.com/shinyaoguri/metaphor/issues/293) で扱われる予定です。

<!-- tutorial-snippet: 05-ThreeD/06-Material -->
```swift
import metaphor

@main
final class Material: Sketch {
    var config: SketchConfig {
        SketchConfig(width: 640, height: 360, title: "Material")
    }

    let roughnessValues: [Float] = [0.05, 0.25, 0.5, 0.75, 1.0]

    func setup() {
        noLoop()
    }

    func draw() {
        background(14)
        noStroke()

        ambientLight(70)
        directionalLight(0.4, 0.85, -0.35)
        directionalLight(-0.6, -0.3, -0.5, color: Color(r: 0.45, g: 0.5, b: 0.6))
        pointLight(320, 20, 340, color: .white, falloff: 0.0015)

        fill(240, 220, 195)

        // 上の段は非金属（metallic 0）、下の段は金属（metallic 1）。
        // 列ごとに roughness だけを変える
        for (row, metal) in [Float(0), 1].enumerated() {
            for (col, rough) in roughnessValues.enumerated() {
                push()
                translate(110 + Float(col) * 115, 140 + Float(row) * 112, 0)
                metallic(metal)
                roughness(rough)      // roughness を呼ぶと PBR モードに切り替わる
                sphere(42)
                pop()
            }
        }

        fill(200)
        textSize(12)
        textAlign(.center)
        for (col, rough) in roughnessValues.enumerated() {
            text("roughness \(rough)", 110 + Float(col) * 115, 46)
        }
        textAlign(.left)
        text("metallic 0", 8, 144)
        text("metallic 1", 8, 256)
    }
}
```

## 5.7 影

![灰色の床に立つ板・球・円柱と、それぞれの真下へ落ちた影](https://i.gyazo.com/3647b5df3178d774cc5cf476550c0e75.png)

影は既定では出ません。`setup()` で有効にします。

```swift
func setup() {
    enableShadows(resolution: 2048)   // シャドウマップの解像度
    shadowBias(0.002)                 // 縞（シャドウアクネ）が出たら調整する
}
```

影を落とすのは**平行光**です。5.5 の規約どおり、渡すのは光が進む向きなので、`directionalLight(0.3, 1, -0.35)` なら左上の手前から差して、影は右下の奥へ伸びます。

影が出ないときの見どころは 3 つです。

1. **受ける面があるか** — 影は面の上にしか映りません。床になる `plane()` を置きます
2. **光の向きは合っているか** — y の符号を逆にすると下から差す光になり、影は上に伸びます
3. **`enableShadows()` を呼んだか** — `draw()` の中で毎フレーム呼ぶ必要はありません

`resolution` はシャドウマップの一辺のピクセル数です。上げるほど輪郭が滑らかになり、GPU メモリを使います。輪郭がギザギザなら上げ、面に縞模様が出るなら `shadowBias()` を上げます。

環境光（`ambientLight()`）は影の中でも減衰しません。**影の中のディテールはこの値で決まります**。真っ黒な影にしたければ環境光を下げます。

<!-- tutorial-snippet: 05-ThreeD/07-Shadow -->
```swift
import metaphor

@main
final class Shadow: Sketch {
    var config: SketchConfig {
        SketchConfig(width: 640, height: 360, title: "Shadow")
    }

    func setup() {
        noLoop()
        // シャドウマップを有効にする。解像度を上げるほど輪郭が滑らかになる
        enableShadows(resolution: 2048)
        // 面が自分自身に落とす縞（シャドウアクネ）が出るときに調整する
        shadowBias(0.002)
    }

    func draw() {
        background(12)
        noStroke()

        ambientLight(45)
        // 影を落とすのは平行光。「光が進む向き」なので y が正なら上から差す。
        // z を負にすると手前から奥へ差し、こちらを向いた面が明るくなる
        directionalLight(0.3, 1, -0.35)

        // 影を受ける床
        fill(120)
        push()
        translate(320, 300, -40)
        rotateX(PI / 2)
        plane(900, 700)
        pop()

        // 影を落とす 3 つの形。床からの高さを変えてある
        fill(235, 180, 90)
        push()
        translate(180, 215, 20)
        rotateY(0.6)
        box(90)
        pop()

        fill(110, 190, 200)
        push()
        translate(330, 190, 40)
        sphere(52)
        pop()

        fill(230, 90, 70)
        push()
        translate(470, 220, 0)
        cylinder(radius: 40, height: 110)
        pop()

        fill(200)
        textSize(12)
        text("enableShadows() + directionalLight(0.3, 1, -0.35)", 22, 34)
    }
}
```

## 5.8 テクスチャ

![市松模様のテクスチャを、box・sphere・自分で UV を渡した面の 3 つに貼っている](https://i.gyazo.com/b3f55258588422edd77e14fdc16711a0.png)

面に画像を貼るには `texture()` を呼んでから形を描きます。画像はファイルから読んだもの（`loadImage()`、第 2 部 2.8）でも、その場で作ったもの（`createImage()`、2.9）でも構いません。

```swift
texture(img)
box(130)      // 以降の 3D シェイプに貼られる
noTexture()   // 解除
```

組み込みプリミティブは UV（画像のどこを面のどこに貼るかの対応）を持っているので、`texture()` を呼ぶだけで貼れます。実行結果の左と中央が、同じ市松模様を `box` と `sphere` に貼ったものです。

### UV を自分で渡す

`beginShape3D()` で作る形には UV がありません。頂点ごとに指定します。

```swift
vertex(x, y, z, u, v)   // u, v は 0〜1
```

`(0, 0)` が画像の左上、`(1, 1)` が右下です。実行結果の右は、4 隅にこの対応を割り当てた四角形です。三角形 2 枚で作っているので、同じ頂点を 2 度書く形になります。

UV を渡さない `vertex(x, y, z)` と混ぜた場合、テクスチャは無視されて `fill()` の色で塗られます。

### いまできないこと

UV の自動生成・法線マップ・PBR テクスチャ（金属度や粗さを画像で与える）はまだありません。貼れるのは色（アルベド）だけです。[#293](https://github.com/shinyaoguri/metaphor/issues/293) で扱われる予定です。

<!-- tutorial-snippet: 05-ThreeD/08-Texture -->
```swift
import metaphor

@main
final class Texture: Sketch {
    var config: SketchConfig {
        SketchConfig(width: 640, height: 360, title: "Texture")
    }

    var checker: MImage!

    func setup() {
        noLoop()

        // 画像はファイルから読むだけでなく、その場で作れる（第 2 部 2.9 と同じ手）
        let size = 128
        checker = createImage(size, size)
        checker.loadPixels()
        for y in 0..<size {
            for x in 0..<size {
                let index = (y * size + x) * 4
                let isLight = ((x / 16) + (y / 16)) % 2 == 0
                checker.pixels[index] = isLight ? 240 : 40            // R
                checker.pixels[index + 1] = isLight ? 190 : 90        // G
                checker.pixels[index + 2] = UInt8(60 + x)             // B は横方向のグラデーション
                checker.pixels[index + 3] = 255
            }
        }
        checker.updatePixels()
    }

    func draw() {
        background(16)
        lights()
        noStroke()

        // 組み込みプリミティブは UV を持っているので、texture() を呼ぶだけで貼れる
        push()
        translate(130, 150, 0)
        rotateX(-0.5)
        rotateY(0.7)
        texture(checker)
        box(130)
        pop()

        push()
        translate(330, 150, 0)
        rotateY(0.5)
        texture(checker)
        sphere(72)
        pop()

        // 自分で貼るときは頂点ごとに UV を渡す。(0,0) が画像の左上、(1,1) が右下
        push()
        translate(520, 150, 0)
        rotateY(-0.45)
        texture(checker)
        beginShape3D(.triangles)
        vertex(-75, -75, 0, 0, 0)
        vertex(75, -75, 0, 1, 0)
        vertex(75, 75, 0, 1, 1)
        vertex(-75, -75, 0, 0, 0)
        vertex(75, 75, 0, 1, 1)
        vertex(-75, 75, 0, 0, 1)
        endShape3D()
        pop()

        noTexture()
        fill(200)
        textSize(12)
        textAlign(.center)
        text("box に貼る", 130, 290)
        text("sphere に貼る", 330, 290)
        text("UV を自分で渡す", 520, 290)
    }
}
```

## 5.9 メッシュとモデル

![頂点から組んだオレンジの四面体と、同じトーラスを 3 回描いた水色のリング](https://i.gyazo.com/1256178e86ad976538f9a3d611c96de6.png)

組み込みの形で足りないときは、頂点を自分で並べます。2D の `beginShape()` と同じ考え方で、3 引数の `vertex()` を使います。

```swift
beginShape3D(.triangles)
normal(nx, ny, nz)          // これ以降の頂点の面の向き
vertex(x, y, z)
vertex(x, y, z)
vertex(x, y, z)
endShape3D()
```

### 法線を忘れると真っ黒になる

3D の明るさは「面の向きと光の向きの関係」で決まります。その面の向きが**法線**で、`normal()` で渡します。渡さないと陰影が付かず、光を置いても平坦に見えます。

法線は 3 頂点から計算できます。実行結果の四角錐は、面ごとにこの計算をしています。

```swift
let n = normalize(cross(b - a, c - a))
normal(n.x, n.y, n.z)
```

このとき**頂点を回す向き（ワインディング）で法線の向きが決まります**。逆に回すと法線が内側を向き、外から見た面が真っ黒になります。「形は出ているのに暗い」ときは、まず頂点の順序を疑います。

### メッシュとして持っておく

毎フレーム頂点を並べ直す代わりに、**`Mesh` として 1 度だけ作る**こともできます。

```swift
var ring: Mesh!

func setup() {
    ring = createTorusMesh(ringRadius: 38, tubeRadius: 12)
}

func draw() {
    push(); translate(300, 180, 0); mesh(ring); pop()
}
```

`createBoxMesh` / `createSphereMesh` / `createPlaneMesh` / `createCylinderMesh` / `createConeMesh` / `createTorusMesh` があり、それぞれ同名のプリミティブと同じジオメトリを返します。位置と向きは描くときの変換行列が決めるので、1 つのメッシュを何度でも使い回せます。

ファイルから読むなら `loadModel()` です。OBJ / USDZ / ABC に対応し、既定でバウンディングボックスを正規化（`normalize: true`）してから返します。

```swift
if let model = loadModel("data/bunny.obj") {
    mesh(model)
}
```

大きなモデルの読み込みは `loadModelAsync()` でメインスレッドの外に出せます。実際の使い方は [`Basics/Shape/LoadDisplayOBJ`](https://github.com/shinyaoguri/metaphor/tree/main/Examples/Basics/Shape/LoadDisplayOBJ) にあります。

<!-- tutorial-snippet: 05-ThreeD/09-Mesh -->
```swift
import metaphor

@main
final class Mesh3D: Sketch {
    var config: SketchConfig {
        SketchConfig(width: 640, height: 360, title: "Mesh 3D")
    }

    // setup() で 1 度だけ作り、draw() で何度でも描くメッシュ
    var ring: Mesh!

    func setup() {
        noLoop()
        ring = createTorusMesh(ringRadius: 38, tubeRadius: 12)
    }

    func draw() {
        background(16)
        noStroke()
        ambientLight(60)
        directionalLight(0.35, 0.8, -0.5)

        // 左: 頂点を自分で並べて作った四角錐
        fill(235, 180, 90)
        push()
        translate(150, 185, 0)
        rotateX(-0.35)
        rotateY(0.7)
        pyramid(base: 150, height: 150)
        pop()

        // 右: 同じ Mesh を 3 回描く。位置と向きは現在の変換行列が決める
        fill(110, 190, 200)
        for i in 0..<3 {
            push()
            translate(380 + Float(i) * 100, 185, Float(i) * -50)
            rotateX(-0.85)
            rotateZ(Float(i) * 0.6)
            mesh(ring)
            pop()
        }

        fill(200)
        textSize(12)
        textAlign(.center)
        text("beginShape3D で組む", 150, 330)
        text("同じ Mesh を 3 回描く", 480, 330)
    }

    /// 四角錐を三角形で組む。底面は xz 平面、頂点は真上（y が負の向き）。
    private func pyramid(base: Float, height: Float) {
        let h = base / 2
        let apex = Vec3(0, -height / 2, 0)
        let corners = [
            Vec3(-h, height / 2, -h),
            Vec3(h, height / 2, -h),
            Vec3(h, height / 2, h),
            Vec3(-h, height / 2, h),
        ]

        // 頂点を回す向き（ワインディング）で法線の向きが決まる。逆に回すと
        // 法線が内側を向き、外から見た面が真っ暗になる
        beginShape3D(.triangles)
        for i in 0..<4 {
            triangle3D(apex, corners[i], corners[(i + 1) % 4])   // 側面
        }
        triangle3D(corners[0], corners[2], corners[1])           // 底面
        triangle3D(corners[0], corners[3], corners[2])
        endShape3D()
    }

    /// 3 頂点を、面の向き（法線）付きで送る。法線が無いと陰影が付かない。
    private func triangle3D(_ a: Vec3, _ b: Vec3, _ c: Vec3) {
        let n = normalize(cross(b - a, c - a))
        normal(n.x, n.y, n.z)
        vertex(a.x, a.y, a.z)
        vertex(b.x, b.y, b.z)
        vertex(c.x, c.y, c.z)
    }
}
```

## 5.10 大量の 3D

![4000 個の小さな立方体を球状に並べた、緑から青へ変わるかたまり](https://i.gyazo.com/06491e2a8fd0f4073b8ddf30fb6556f9.png)

同じ形をたくさん描くとき、metaphor は**自動でまとめます**。`for` で `box()` を並べても、条件が揃っていれば 1 回の描画命令になります。

まとまる条件は「**同じメッシュ・同じマテリアル・同じテクスチャ・同じストローク設定**が続くこと」です。`fill()` の色はインスタンスごとに持てるので、色違いはまとまったままです。逆に、途中でライトやカメラ、マテリアルを変えるとそこで区切られます。

つまり、こう書くだけでも速く描けます。

```swift
for p in points {
    push(); translate(p.x, p.y, p.z); box(8); pop()   // まとめて描かれる
}
```

### 明示的にまとめる

数が万の単位になると、1 個ずつ `push()` / `translate()` / `pop()` を評価する CPU の側が重くなります。そのときは変換行列の配列を渡します。

```swift
drawInstanced(cube, transforms: transforms, colors: colors)
```

`transforms` は**現在の変換行列に対するローカル変換**なので、呼び出す前の `translate()` や `rotateY()` は全インスタンスにまとめて効きます。実行結果は 4000 個の立方体を球面上に配置したもので、配置は `setup()` で 1 度だけ作り、`draw()` は渡すだけです。

行列は補助のイニシャライザで組み立てられます。

```swift
float4x4(translation: Vec3(x, y, z)) * float4x4(scale: Vec3(repeating: s))
```

色をインスタンスごとに変えられるのは `fill` だけです。マテリアル・テクスチャ・ストロークは全インスタンスで共通になります。

<!-- tutorial-snippet: 05-ThreeD/10-Instancing -->
```swift
import metaphor

@main
final class Instancing: Sketch {
    var config: SketchConfig {
        SketchConfig(width: 640, height: 360, title: "Instancing")
    }

    let cubeCount = 4000
    let radius: Float = 135

    var cube: Mesh!
    var transforms: [float4x4] = []
    var colors: [Color] = []

    func setup() {
        noLoop()
        noStroke()

        // 描くたびに作り直さない。メッシュも配置も setup() で 1 度だけ用意する
        cube = createBoxMesh(7)

        transforms.reserveCapacity(cubeCount)
        colors.reserveCapacity(cubeCount)

        // 球面上に均等に撒く（黄金角を使うフィボナッチ球）
        let golden = PI * (3 - sqrt(5))
        for i in 0..<cubeCount {
            let t = Float(i) / Float(cubeCount - 1)
            let y = 1 - t * 2                      // 上から下へ -1…1
            let r = sqrt(max(0, 1 - y * y))
            let angle = golden * Float(i)
            let position = Vec3(cos(angle) * r, y, sin(angle) * r) * radius

            transforms.append(
                float4x4(translation: position)
                * float4x4(scale: Vec3(repeating: 0.6 + r * 0.9))
            )
            colors.append(Color(hue: 0.55 - t * 0.35, saturation: 0.75, brightness: 1))
        }
    }

    func draw() {
        background(12)
        ambientLight(70)
        directionalLight(0.3, 0.9, -0.35)

        // 呼び出し前の変換が全インスタンスに効く
        push()
        translate(width / 2, height / 2, -60)
        rotateY(0.6)
        rotateX(-0.35)
        drawInstanced(cube, transforms: transforms, colors: colors)
        pop()

        fill(200)
        textSize(12)
        text("\(cubeCount) 個の立方体を drawInstanced() の 1 回で描く", 22, 336)
    }
}
```
