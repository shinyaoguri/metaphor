# metaphor sketch authoring guide

> Use this compact guide when generating or editing user sketches with
> `import metaphor`. For full API signatures, use `llms.txt`.

## Goal

Generate complete, real-time-safe creative coding sketches for metaphor users.
Prefer one self-contained `App.swift` unless the user asks for multiple files.

## Minimal Shape

```swift
import metaphor

@main
final class MySketch: Sketch {
    var config: SketchConfig {
        SketchConfig(width: 1280, height: 720, title: "MySketch")
    }

    func setup() {
        // Load assets and create long-lived resources here.
    }

    func draw() {
        background(13)
        fill(255)
        circle(width / 2, height / 2, 120)
    }
}
```

## Authoring Rules

- Use `setup()` for assets, audio/video input, compute kernels, physics worlds,
  particle systems, and other long-lived resources.
- Keep `draw()` real-time safe. Update state and render; do not repeatedly load
  files, allocate large buffers, or rebuild expensive resources every frame.
- Use `time`, `deltaTime`, and `frameCount` for animation.
- Pair `push()` with `pop()` and `pushStyle()` with `popStyle()`.
- Use `width` and `height` instead of hardcoded canvas bounds when possible.
- Colors default to Processing-style `0...255` ranges for RGB/gray/alpha
  (`fill(255, 102, 51)`, `background(13)`). Use `colorMode(.rgb, 1, 1, 1, 1)`
  first if you want normalized `0...1` values. Use `Color` constants or one
  range consistently in one sketch.
- For export or deterministic rendering, prefer offline-render APIs rather than
  wall-clock timing.

## Tunable Values (`@Param`)

Declare values you expect to tune — radii, counts, speeds, colors, modes — with
`@Param`. They persist across restarts in `.metaphor/params/params.json` and can
be changed **without rebuilding**.

```swift
@main final class MySketch: Sketch {
    @Param(min: 10, max: 200) var radius: Float = 50
    @Param var showGrid: Bool = true
    @Param(choices: ["add", "multiply"]) var mode: String = "add"

    func draw() {
        circle(width / 2, height / 2, radius)   // read it like a normal property
    }
}
```

Supported types: `Float` / `Double` / `Int` / `Bool` / `String` (with optional
`choices`) / `Color` / `Vec2` / `Vec3`. Names default to the property name; pass
`@Param("myName")` to override. Opt out with `METAPHOR_PARAMS=0`.

Call `gui.params()` inside `draw()` to get a control panel for every declared
parameter (sliders, toggle, color picker, and a button that cycles `choices`).
Dragging a widget writes through the same store, so the value is persisted and
restored just like an external write. `gui.param("radius")` places a single
parameter when laying the panel out by hand. Declare `min` / `max` on numbers —
otherwise the slider range is guessed from the first displayed value.

For AI assistants: to retune a running sketch, call the `params` MCP tool to see
what is tunable and `set_param` to change values (`metaphor mcp`; works while a
human has the sketch open in `metaphor watch` too). Without MCP, do the same over
files: write `.metaphor/params/set-request.json` atomically (`.tmp` → rename) with
a **new** `id` each time — `{"id": "<unique>", "values": {"radius": 120}}` — then
read back `.metaphor/params/params.json` and check `appliedRequestId` (rejected
values are explained in `warnings`). Either way the round trip takes one frame;
**edit code only for structural changes**, not for tuning numbers.

A Probe snapshot carries the values that produced it: `frame.json` has
`params{revision, values}` alongside the image, so you never have to guess whether
`params.json` was read before or after the frame you are looking at.

## Common Requests

### 2D Generative Motion

Use arrays of positions/velocities, update with `deltaTime`, draw with `circle`,
`line`, `rect`, gradients, and blend modes. Avoid creating thousands of Swift
objects per frame; reuse arrays.

### 3D Scene

In `draw()`, call `background`, configure lights, then draw primitives.
Use `push()` / `pop()` around each object transform.

The default camera is pixel space, like Processing's `P3D`: one world unit is
one pixel, the origin is the top-left corner, and `+y` points down. So size 3D
primitives in pixels (`box(120)`, not `box(1.2)`) and translate to
`(width / 2, height / 2)` to work around the center. Call `camera(...)` only
when you want a different viewpoint — it replaces the pixel-space default.

```swift
lights()
push()
translate(width / 2, height / 2, 0)
rotateY(time)
box(120)
pop()
```

### Audio Reactive

Create the analyzer once:

```swift
var audio: AudioAnalyzer!

func setup() {
    audio = createAudioInput()
}
```

In `draw()`, call `audio.update()` if the API requires it for the chosen source,
then map band energy or amplitude into visual parameters.

### Video / Image

Load once in `setup()`. For video, call `play()` or `loop()` once, update per
frame, then draw with `image(video, x, y, w, h)`.

### Particles

Prefer the built-in GPU particle system for very large counts. Create it once,
update it in `compute()` or `draw()` as the API expects, and draw it once per
frame.

### Shaders

Use `createPostEffect` / `createMaterial` for user-supplied MSL. Keep shader
source strings small in generated answers unless the user specifically asks for
a full custom shader.

## Debugging Hints

- If a symbol is unknown, search `llms.txt` before inventing an API.
- If a sketch is blank, check that `background`, `fill`/`stroke`, camera, and
  object positions are sensible for the canvas.
- If performance is poor, move resource creation out of `draw()` and reduce CPU
  per-frame allocations.
- If assets fail to load, prefer explicit file paths or bundle resources and
  show where the user should put them.

## Output Style For AI Assistants

- Return complete Swift code when asked to create a sketch.
- Explain only the key controls and resource requirements.
- Do not include placeholder APIs that are not in `llms.txt`.
- Prefer metaphor-native APIs over generic Metal code unless requested.
