- The Processing originals that were never licensed for redistribution are gone — 144
  `.pde` sketches and 61 `.json` metadata files across 95 example packages
  ([#1191](https://github.com/shinyaoguri/metaphor/issues/1191)). The upstream repository
  [processing/processing-examples](https://github.com/processing/processing-examples) ships
  no license file at all; one sentence in its README puts sketches *without* a credit line
  in the public domain and leaves the copyright on the credited ones with their authors,
  granting nothing. Attribution cannot cure a missing grant, so an MIT repository could not
  keep redistributing them — and neither could anyone redistributing this one. The 170
  public-domain `.pde` still ship beside their ports.
- Nothing to do when upgrading: no target declared these as resources and nothing read them
  at runtime, so no example builds or renders differently. To read an original, follow the
  URL now written into the first lines of that example's `App.swift` — the Examples tree
  mirrors Processing's own hierarchy, so it is the matching upstream path. The `.json`
  beside each example is metaphor's own metadata now; the 61 that replaced a removed
  original were rewritten from the Swift port, and `docs/ai/examples-index.{md,json}` is
  unchanged in size and shape.
