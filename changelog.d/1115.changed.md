- The DocC catalog's prose is now written in English, matching the rest of the API
  reference ([#1115](https://github.com/shinyaoguri/metaphor/issues/1115)). The landing
  page [`metaphor`](https://shinyaoguri.github.io/metaphor/reference/documentation/metaphor/)
  and the 11 module landing pages used to stay Japanese while every symbol page around
  them was English, so `/reference/` mixed the two languages on the pages readers hit
  first. English is the canon for the reference ([ADR-0011](https://github.com/shinyaoguri/metaphor/blob/main/docs/adr/0011-docc-english-canon-japanese-generated.md)),
  and the Japanese wording moved into the `docs/reference/i18n/ja.json` ledger that
  generates [`/reference/ja/`](https://shinyaoguri.github.io/metaphor/reference/ja/documentation/metaphor/) —
  so the Japanese reference reads exactly as before. Nothing to do when upgrading.
- The Japanese reference now also translates the Topics group headings
  ([#1115](https://github.com/shinyaoguri/metaphor/issues/1115)). Group names that DocC
  generates itself — "Instance Properties", "Initializers", "Enumeration Cases" and the
  rest — used to show in English on every page of `/reference/ja/`; they are part of the
  ledger now and read as Japanese.
