- `dispatch(_:threads:)` / `dispatch(_:width:height:)` / `computeBarrier()` /
  `updateParticles(_:)` no longer fail silently when called outside `compute()`.
  They still do nothing there — GPU work can only be encoded during the compute
  phase — but debug builds now warn once per API instead of leaving you with a
  kernel that never ran and no diagnostic at all. The documentation for those
  methods now states the `compute()`-only constraint
  ([#1092](https://github.com/shinyaoguri/metaphor/issues/1092))
