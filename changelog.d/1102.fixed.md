- Building the library with optimizations (`swift build -c release`) no longer
  crashes the Swift compiler on Xcode 26.4.1. `MetaphorML`'s `MLMultiArray`
  reader passed a conversion closure into a generic local function, which took
  down the SIL optimizer with `signal 11` under `-O -enable-default-cmo`; the
  reader now uses two closure-free generic functions instead. 24 of the 343
  example packages failed to build because of this
  ([#1102](https://github.com/shinyaoguri/metaphor/issues/1102))
