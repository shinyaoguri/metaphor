- Offscreen buffers now **start out transparent**. `createGraphics()` / `createGraphics3D()` used
  to begin with an opaque black backdrop, which covered whatever was underneath when the buffer
  was placed with `image()` or used as the foreground of a `MergePass(.alpha)`. They now begin
  fully transparent (alpha 0), matching p5.js and Processing, so an offscreen buffer works as a
  layer without any extra call. The main canvas is unchanged — it still starts opaque black.
  To keep the old behaviour, paint the backdrop yourself:

  ```swift
  pg.beginDraw()
  pg.background(0)   // add this line for the previous opaque black backdrop
  // ...
  pg.endDraw()
  ```

  ([#914](https://github.com/shinyaoguri/metaphor/issues/914))
