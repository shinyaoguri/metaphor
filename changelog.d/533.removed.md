- The DocC catalog is now API reference only: the two article pages
  `/documentation/metaphor/gettingstarted` and
  `/documentation/metaphor/architecture` are gone
  ([#533](https://github.com/shinyaoguri/metaphor/issues/533)). Nothing was
  dropped — the minimum you need to start (requirements, the SwiftPM snippet,
  a first sketch) is folded into the landing page
  [`metaphor`](https://shinyaoguri.github.io/metaphor/reference/documentation/metaphor/),
  the step-by-step walkthrough lives in the
  [tutorial](https://shinyaoguri.github.io/metaphor/tutorial/), and the
  implementation notes (frame lifecycle, shader compilation, instancing) live in
  `docs/ai/README.md`. DocC cannot lay out prose the way the tutorial can, so
  articles now belong there and the catalog stays a place to look up a symbol.
