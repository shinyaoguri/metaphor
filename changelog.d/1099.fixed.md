- `OrbitCamera.damping` no longer changes how far a drag rotates the camera. It
  used to add the drag delta straight into the velocity that `update()` then
  integrates and decays, so a sustained drag settled at `d / (1 - damping)` per
  frame — `damping = 0.86` made every drag 7.1x as strong, and `damping = 0.95`
  20x. The drag delta is now scaled by `1 - damping` on the way in, so
  `sensitivity` means radians per pixel whatever the damping is, and `damping`
  only sets how long the glide lasts after you let go
  ([#1099](https://github.com/shinyaoguri/metaphor/issues/1099)).
  - **If you set `damping` and tuned `sensitivity` around it, drop the
    correction.** A sketch using `sensitivity = 0.005 * (1 - damping)` to cancel
    the old gain now rotates `1 - damping` times too slowly; plain
    `sensitivity = 0.005` restores it.
  - `damping` is now clamped to `[0, 1)` internally. Reading the property still
    returns whatever you assigned, but a value of `1` no longer spins the camera
    forever (and, with the gain correction, no longer freezes it either).
