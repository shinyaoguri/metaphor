- `enablePerformanceHUD()` no longer reports `GPU: 0.00 ms` when the GPU time
  has not been measured yet. A `noLoop()` sketch draws exactly one frame, and
  the GPU timestamps only arrive from the command buffer's completion handler
  *after* that frame is finished — so its HUD always showed a fabricated
  `0.00`. The HUD now prints `GPU: -- ms` until a real measurement lands, the
  same way `FPS` and `Frame` report an unavailable value
  ([#698](https://github.com/shinyaoguri/metaphor/issues/698)). The first frame
  of a looping sketch is covered too. `MetaphorRenderer` gained
  `lastGPUDurationMs: Double?` for this; the existing `lastGPUStartTime` /
  `lastGPUEndTime` are unchanged and still read `0` before the first frame
  completes ([#1016](https://github.com/shinyaoguri/metaphor/issues/1016))
